DramaLive card page for Media Station X

Folder placement:
Put the "dramalive" folder directly inside the existing MSX repository root.

Files:
- index.html
- style.css
- app.js

This is a simple ES5-compatible launch page. The OPEN DRAMALIVE link opens:
https://web.dramalive.cc/

Important:
This page does not fix compatibility problems inside the DramaLive website itself.
If the official site displays a blank or black page on your Samsung TV,
that is likely an issue inside the website/browser compatibility and requires
separate investigation.
